MOVE CLOCK 운동 타이머

애플 단축어로 특정 루틴 열기
1. 웹사이트의 루틴 카드에서 [링크]를 눌러 URL을 복사합니다.
2. 아이폰 단축어 앱 > + > URL 동작에 해당 주소를 넣습니다.
3. [URL 열기] 동작을 추가하고 단축어 이름을 정합니다.
4. 단축어를 탭하면 해당 루틴의 준비 화면이 열립니다. 알림음 활성화를 위해 [운동 시작]을 한 번 눌러주세요.

기능
- 루틴 여러 개 추가/편집/삭제, 운동별 세트/운동 시간/휴식 시간 저장
- 운동 시간 0초 = 직접 [세트 완료]를 눌러 휴식 시작
- 휴식 시작 알림음 및 한국어 음성, 종료 5초 전부터 카운트다운
- 자동 진행, 일시정지, 이전/다음 단계, 소리 테스트
- 같은 브라우저/웹앱 저장소(localStorage)에 루틴 저장
- 배포 후 최초 온라인 방문 시 주요 파일 캐시로 오프라인 실행 지원

중요 제한
- 아이폰 Safari/PWA의 화면 잠금 또는 백그라운드 상태에서는 타이머와 오디오가 중단/지연될 수 있습니다.
- 브라우저 데이터 삭제, Safari와 홈 화면 웹앱의 저장소 차이로 루틴이 달라질 수 있습니다.
- 한국어 TTS의 음질/카운트다운 타이밍은 iOS 버전과 음성 엔진에 따라 다를 수 있습니다.
- 실제 아이폰에서 음성이 나오는지 반드시 먼저 확인하세요.
- 알림음·음성을 포함한 세트 진행은 화면을 켜 둔 상태에서 사용하세요.
